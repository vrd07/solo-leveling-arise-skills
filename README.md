# Solo Leveling ARISE Skills

Turn your AI assistant into **the System** from *Solo Leveling*. Every task becomes a quest, every project a dungeon, and every one of Jinwoo's skills is a ready-made prompt that does real work: Sprint for quick answers, Bloodlust for brutal reviews, Stealth for security checks, **ARISE** to extract value from any content, and more.

Inspired by *Solo Leveling Season 2: Arise from the Shadow*.

## What's inside

[`SKILL.md`](SKILL.md) contains:

- **The Gate:** one prompt that classifies any task, picks a rank (E to S) and chooses the right skills
- **20+ skills as prompts:** passive, active and Monarch skills, each mapped to a real task type
- **A shadow army:** Igris, Iron, Tank, Tusk, Kaisel, Beru as specialist modes (review, testing, bulk work, research, logistics, debugging)
- **Quests:** Daily Quest, Emergency Quest, Job Change Quest, Hidden Quest
- **Dungeons:** Double Dungeon, Red Gate, Dungeon Break and Demon Castle as project protocols
- **Status window, stats, XP and titles** that track real progress, never fake progress

## Install

**Claude (claude.ai / desktop app):** create a skill named `solo-leveling-system` and upload `SKILL.md`.

**Claude Code:** copy the file to `~/.claude/skills/solo-leveling-system/SKILL.md`.

**Any other chatbot:** paste the contents of `SKILL.md` as the first message or the system prompt.

## Try it

```
status
daily quest
gate: plan my portfolio website
Bloodlust rank A: review my resume
ARISE: <paste an article or meeting notes>
summon Beru: this Python script throws KeyError
job change: student → quant developer
```
